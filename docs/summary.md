以下是学习过程中的注意事项。


# 项目管理

1. 使用GitHub完成项目管理，用好Team Planning，Kanban， Bug Tracker。
2. 提升分工合作能力。


# 软件工程生命周期

1. 理解每个生命周期需要完成的重要任务。
2. 重视设计环节，根据要求完成原型设计和技术设计，可用软件代码验证设想，但不急于编写代码。参考课程幻灯片第2部分。
3. 设计阶段，需要理解系统结构，理解每一个部件的功能。
4. 设计阶段，深入理解开源技术框架的原理。
5. 设计阶段，技术选型，需要用批判性思维。例如前端为什么需要用成熟框架，选择Vue还是React？
6. 开发阶段，掌握提高软件质量的方法，在使用软件质量工具的前提下，有效、有效率地使用Vibe Coding，提升软件质量意识，不满足于“程序能跑”。



# 工程素养

1. 提升工程意识，课程的目标是做工程级别的作品，不是写作业。

# 学生可能存在的问题

1. 不习惯GitHub协作。
2. 缺乏分工合作经验。
3. 对原型设计和技术设计环节不够重视，急于编写代码。
4. 未能深入理解开源技术框架的原理。
5. 无法充分发挥Vibe Coding的能力。



# 解决问题的方法

1. 提升工程意识，课程的目标是做作品，不是写作业。
2. 系统思维，理解系统的每一个环节。
3. 批判性思维，技术选型需要注意的方面。
4. 有效、有效率地使用Vibe Coding。
5. 掌握提高软件质量的方法。

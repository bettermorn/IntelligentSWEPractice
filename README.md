# Intelligent Software Engineering Practice
面向软件工程研一学生的智能软件工程实践课程。本课程学习对象是对应用人工智能技术完成工程类软件作品感兴趣的学生。
本课程是项目式实践学习。学生通过学习和探讨专业软件开发相关理论，定义软件作品需要解决的问题，以小组分工协作的方式全面系统地应用软件工程方法论以及人工智能技术最终完成软件作品。学生将通过完成定义问题、设计、开发和测试功能以及发布作品等5个子任务，实践软件开发（包括人工智能算法模型）、产品设计、项目管理和敏捷开发等知识，熟悉开源软件，熟练掌握软件工程方法论，提高实践创新能力。学生通过探讨和实践人工智能在软件工程的应用以及对软件工程发展的影响，建立前瞻性观点，为后期研究打下理论和实践基础。

# 课程目标
- 目标1：掌握软件开发整个生命周期，即分析、设计、开发、测试和维护的行业方法论，利用团队协作工具和知识技能完成软件作品，使学生具备面向复杂软件工程问题开展需求分析、技术建模、系统设计、算法实现、实验验证和工程集成的能力，能够运用人工智能技术和工具解决智能软件开发中的典型问题。 
- 目标2：理解软件行业中不同专业人员如产品经理、架构师、开发工程师和质量保证工程师的职业特点，为成为能够创造性地从事实际工作的高层次应用型专门人才做好准备。
- 目标3：掌握学习虚拟现实、区块链、数据分析和人工智能等新技术的方法。
- 目标4：掌握研究智能软件工程（Intelligent Software Engineering, ISE）尤其是（包括面向软件工程的人工智能（AI for Software Engineering, AI4SE））案例和论文的方法，提高文献阅读能力，提升学术演讲表达能力，使学生系统掌握人工智能与软件工程交叉融合的基础理论、关键技术、研究方法和前沿发展，理解人工智能在软件需求分析、设计开发、测试维护、运维管理等环节中的应用机理，熟悉智能软件系统构建所涉及的数据处理、模型训练、实验评估、工程部署及伦理安全等基本知识。
- 目标5: 掌握专业技术或实践创新的理论知识和方法论，即在真实职业场景中，创造性地运用专业知识，解决行业产业实际问题的能力。
- 目标6：发展适应行业要求的品行特征，包括适应性、创造性、严谨性、自我指导和热情等个性特征。培养学生严谨求实的科研素养、面向复杂系统的工程素养、主动探索的创新素养以及规范合作的职业素养，强化其人工智能伦理意识、数据安全意识和社会责任意识，形成持续学习、理性应用技术和服务实际需求的综合素质。



# 课程教学方法
本课程为项目式学习实践课程。教师将应用概念解释、互动讨论、示范的方法，指导学生完成项目式实践。为降低实践学习曲线坡度，教师将帮助学生分解实践任务，并在实践任务中引导学生应用和理解工程实践的理念、体系、流程、方法和平台，教师将为学生指导较复杂的实践环节，并提供示范案例。教师也将提供解决实际问题的虚拟现实、区块链、数据分析和人工智能等新一代信息技术的学习路线和参考代码等。学生在实践中将会应用相关理论知识，如系统工程方法、MBSE（Model-Based Systems Engineering，基于模型的系统工程）、面向对象分析方法、敏捷开发方法论、代码质量管理等。学生实践成果的顺利完成，需要学生在记忆、理解和应用认知水平的基础上，达到高阶认知水平即分析、评估和创造。本课程能够帮助学生在高阶认知水平方面得到相应的能力训练。

# 课程大纲
本课程包括理论、实践及检查和汇报三个部分。
理论部分是指软件工程、软件作品以及人工智能涉及的相关理论。实践部分是指学生在教师指导下，包括与AI协作完成软件产品的具体过程。教师将提供足够的指导资源。检查和汇报部分是指教师确认学生每阶段实践任务的情况，并给予指导，也包括学生分享智能软件工程论文学习体会。

课程共 17 周，分为五个部分：根据软件生命周期分为5个部分，包括分析、设计、开发、测试和发布。

1. **第一部分：系统分析**（第 1–2 周）—— 定义工程问题与软件功能
2. **第二部分：系统设计**（第 3–6 周）—— 原型设计、文献阅读与技术方案
3. **第三部分：系统开发**（第 7–10 周）—— 系统功能开发与代码质量
4. **第四部分：系统测试**（第 11–13 周）—— 测试用例编写与缺陷修复
5. **第五部分：发布**（第 14–17 周）—— 部署、迭代与作品答辩
